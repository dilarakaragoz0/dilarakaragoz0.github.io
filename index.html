Lilyish Yayin

Lilyish Yayin is a small personal tool that uploads videos created by its owner to the owner's own YouTube channel using the YouTube Data API.

The app only acts on the YouTube account that the user explicitly authorizes through Google's sign-in screen. It does not access any other Google data.
